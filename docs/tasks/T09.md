# T09 — Background worker

Goal: Run OCR + extraction + validation + embedding on the arq worker.

Create or edit
- src/docintel/worker.py
- tests/test_worker.py

Read
- docs/DECISIONS.md
- src/docintel/queue.py
- src/docintel/pipeline/
- src/docintel/extract/
- src/docintel/validate/

Behavior
- Job processes a document end-to-end: parse -> extract -> validate -> store results -> embed.
- Retries on transient failures; marks failed with error.
- Updates job status and processing_history.

Check
```bash
docker compose up -d
PYTHONPATH=src uv run arq docintel.worker.WorkerSettings
PYTHONPATH=src uv run pytest -q tests/test_worker.py
```

Done when
- End-to-end job completes for a sample invoice
- Failure path marks job failed
