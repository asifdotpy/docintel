# T05 — OCR for images and scanned PDFs

Goal: OCR images and scanned PDFs using Tesseract + pdf2image.

Create or edit
- src/docintel/pipeline/ocr.py
- tests/test_ocr.py

Read
- docs/DECISIONS.md
- src/docintel/pipeline/router.py

System packages (install once)
- tesseract-ocr, poppler-utils

Behavior
- ocr.image(path) -> text
- ocr.pdf(path) -> {text, page_count} (render pages -> OCR)
- Light image cleanup (grayscale, threshold) before OCR.
- Poor quality must not crash; return empty text + error flag.

Check
```bash
sudo apt-get install -y tesseract-ocr poppler-utils
PYTHONPATH=src uv run pytest -q tests/test_ocr.py
```

Done when
- Sample scanned PDF/image OCR returns text
- Failure paths covered
