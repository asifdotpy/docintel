# T01 — Runtime skeleton

Goal: Create the FastAPI app, config, database session, and health endpoint so the API boots.

Create or edit
- src/docintel/main.py
- src/docintel/config.py
- src/docintel/db.py
- src/docintel/api/__init__.py
- src/docintel/api/health.py
- alembic.ini
- alembic/env.py
- alembic/versions/ (directory)
- tests/test_health.py

Read
- docs/DECISIONS.md
- docs/PACKAGES.md
- .env.example

Notes
- Package lives under src/. Run with `PYTHONPATH=src` or set in pyproject.
- Config via pydantic-settings reading .env.
- db.py: async SQLAlchemy engine + session factory; sync engine for Alembic.
- Health endpoint: GET /health (or /api/health) returns {"status":"ok"}.
- alembic.ini points at src/docintel models; env.py imports models.

Check
```bash
uv sync --group dev
PYTHONPATH=src uv run pytest -q tests/test_health.py
PYTHONPATH=src uv run uvicorn docintel.main:app --port 8000
curl -s http://localhost:8000/health
```

Done when
- Health test passes
- App boots and /health returns 200
