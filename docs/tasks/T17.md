# T17 — Correcting evaluation metric semantics

Goal: Ensure labeled-field evaluation treats equivalent dates, entity annotations, and null labels according to documented source semantics.

Create or edit
- scripts/eval.py
- src/docintel/evaluation.py
- tests/test_eval.py
- docs/eval/report.md (only metric definitions or figures that can be reproduced from the existing result data)

Read
- scripts/eval.py
- src/docintel/evaluation.py
- tests/test_eval.py
- docs/eval/report.md

Scope
- Verify the label mappings and field semantics from the evaluation code and documented source metadata available there. Do not silently strip address text from a label to improve a match. If the source annotation meaning is ambiguous, preserve the current value and document the limitation.
- Normalize prediction and ground-truth dates to a canonical date only when parsing is unambiguous. Invalid or ambiguous dates must not be guessed into a match.
- Distinguish an unlabeled/null ground-truth field from a field explicitly reviewed and confirmed absent. Exclude unknown nulls from accuracy denominators. Report predictions on unknown-null fields separately; count false positives only for confirmed absence.
- Add focused tests for date formats, entity label semantics, unknown nulls, and confirmed-absence false positives.
- Make any report metric definitions and figures reproducible from the existing result data. Preserve unrelated report edits and do not fabricate results.
- Do not tune the extraction prompt/model on these four labeled samples or optimize for a 100% score. Do not download data or run a new live benchmark in this task.
- Do not edit `eval/results.json`, `SUBMISSION_STATUS.md`, task tracker files, or unrelated files.

Check
```bash
PYTHONPATH=src uv run pytest tests/test_eval.py
```

Done when
- Tests establish the comparison and denominator behavior above.
- Source-specific entity normalization is supported by documented semantics; otherwise no normalization is applied.
- The existing benchmark's counts are not inflated by guessing, removing labeled content, or treating unknown nulls as confirmed absence.
- The check command passes.
