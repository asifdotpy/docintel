# T07 — Invoice schema and LLM extraction

Goal: Define the invoice Pydantic schema and extract fields via Gemini structured outputs.

Create or edit
- src/docintel/extract/__init__.py
- src/docintel/extract/schema.py
- src/docintel/extract/llm.py
- tests/test_extract.py

Read
- docs/DECISIONS.md
- .env.example (GEMINI_*)

Schema fields
- invoice_number, invoice_date, supplier_name, customer_name, subtotal, tax, total, currency, line_items (list of {description, quantity, unit_price, amount})

Behavior
- EXTRACTOR=fake returns deterministic fixture for tests (no network).
- EXTRACTOR=gemini calls Gemini (OpenAI-compatible endpoint) with structured output; missing values -> null, never invented.
- Save prompt in docs/prompts/ (T16) or src; include prompt text.

Check
```bash
EXTRACTOR=fake PYTHONPATH=src uv run pytest -q tests/test_extract.py
```

Done when
- Fake extractor tests pass
- Gemini path works with a real key (manual)
- No hallucinated values
