# T02 — Database schema and migration

Goal: Define all tables and create the initial Alembic migration.

Create or edit
- src/docintel/models.py
- alembic/env.py
- alembic/versions/0001_initial.py
- tests/test_models.py

Read
- docs/DECISIONS.md
- src/docintel/db.py (from T01)

Schema (minimum)
- documents: id, filename, content_type, size, storage_path, status, created_at, updated_at
- document_text: document_id FK, full_text, page_count
- extractions: document_id FK, data (JSONB), model, created_at
- validation_errors: document_id FK, code, message, field, created_at
- jobs: id, document_id FK, kind, status, error, created_at, finished_at
- processing_history: id, document_id FK, event, detail, created_at
- embeddings: document_id FK, vector(384) (pgvector)

Check
```bash
uv run alembic upgrade head
PYTHONPATH=src uv run pytest -q tests/test_models.py
```

Done when
- Migration applies cleanly on a fresh DB
- Model tests pass
