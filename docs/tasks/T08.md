# T08 — Validation rules

Goal: Validate extracted invoices and flag anomalies for manual review.

Create or edit
- src/docintel/validate/__init__.py
- src/docintel/validate/rules.py
- tests/test_validate.py

Read
- docs/DECISIONS.md
- src/docintel/extract/schema.py

Rules
- Missing required fields -> error
- Numeric mismatches: subtotal + tax != total (tolerance) -> error
- Duplicate invoice (same invoice_number + supplier) -> error
- Bad numbers (negative totals, non-numeric) -> error
- Return list of {code, field, message}; empty = valid.

Check
```bash
PYTHONPATH=src uv run pytest -q tests/test_validate.py
```

Done when
- All rules tested
- Duplicate detection works
