# T03 — Upload API and job enqueue

Goal: Accept multi-file uploads, store them, create document rows, and enqueue processing jobs.

Create or edit
- src/docintel/api/uploads.py
- src/docintel/queue.py
- src/docintel/storage.py
- tests/test_uploads.py

Read
- docs/DECISIONS.md
- src/docintel/models.py
- src/docintel/config.py

Endpoints
- POST /api/documents/upload (multipart, multiple files) -> {document_ids, job_ids}
- GET /api/jobs/{id} -> status

Check
```bash
PYTHONPATH=src uv run pytest -q tests/test_uploads.py
```

Done when
- Upload of a valid file returns 200 with ids
- Invalid/corrupt file is rejected or flagged, not crashed
- Job row created with status queued
